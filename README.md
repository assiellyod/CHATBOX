# CHATBOX

A simple private chat interface built with **HTML, Bootstrap 5, and JavaScript** for learning and practice.

## 🌐 Live Website

[Open CHATBOX](https://assiellyod.github.io/CHATBOX/)

## 📌 About

CHATBOX is a beginner-friendly web project designed to practice building a messaging interface. The project will gradually grow from a simple HTML interface into a more complete chat application.

## 🛠️ Technologies

- HTML — page structure
- Bootstrap 5 — styling, responsive layout, and UI components
- JavaScript — interactive features
- GitHub Pages — live website hosting

## 📂 Project Structure

```text
CHATBOX/
├── index.html       # Main webpage + Bootstrap classes
├── script.js        # Interactive features
├── api/             # Practice API structure
└── database/        # Practice data/schema files
```

## 🎨 Styling Rule

This project uses **Bootstrap directly in `index.html`**. There is no custom `style.css`, no `<style>` block, and no inline `style="..."` styling.

## 🚧 Project Status

This project is currently under development. Features will be added step by step while practicing web development.

## 🎯 Learning Goals

- Learn HTML structure
- Practice Bootstrap layouts and components
- Learn JavaScript interactions
- Understand how frontend and backend parts connect
- Practice using GitHub and GitHub Pages
